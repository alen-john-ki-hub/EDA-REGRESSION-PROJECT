# AI Developer Productivity – Regression Analysis Project

This project performs Exploratory Data Analysis (EDA) and Regression Analysis on an AI Developer Productivity dataset using Python libraries such as Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn. The analysis focuses on predicting productivity and understanding the relationship between different developer work factors.

## Project Features

* Data loading and inspection
* Data cleaning and preprocessing
* Statistical analysis
* Correlation analysis
* Data visualization using charts and plots
* Multiple regression models
* Model evaluation using:

  * MAE
  * MSE
  * RMSE
  * R² Score

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Objective

The main objective of this project is to:

* Analyze developer productivity using EDA
* Identify relationships between work habits and productivity
* Build regression models for prediction
* Evaluate model performance using regression metrics

## Output

The project generates:

* Graphs and visual insights
* Correlation analysis
* Regression model predictions
* Performance evaluation metrics
